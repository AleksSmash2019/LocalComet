## LocalComet — OpenAI Build Week 2026

A private, local-first Windows AI assistant built and validated with Codex.

### Installation

1. Download `LocalComet_0.0.0_x64-setup.exe`.
2. Run the installer.
3. Open LocalComet.
4. Open Settings → Models.
5. Install the approved runtime and model.
6. Press Connect and start chatting.

No Ollama, LM Studio, cloud inference provider, or OpenAI API key is required for local inference.
