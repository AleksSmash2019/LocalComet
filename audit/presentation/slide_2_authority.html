Как оценивалась доказательность

Источник Authority

Rust владеет risk policy, approval/grant, host spawn/ownership и terminal state.

Frontend, Python sidecar, model output, UI pill, body text и открытый порт не могут повышать verdict.

Требования к Acceptance

Требуются не только source tests, а independent protected postconditions:

  • Exact PID / desktop / profile
  • Correlated request / action / input digest
  • Before / after bytes
  • No mutation & No replay
  • Exact cleanup

ВАЖНО: Contract test не закрывает native row, если MASTERPROMPT требует protected postcondition.

Классификация Evidence

Класс Значение в этом аудите

B Verified historical / current-code-cutoff evidence
C Source / contract evidence only
G Unsupported for native
